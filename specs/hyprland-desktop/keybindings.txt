   MIT DER MAUS
     Titelleiste ziehen          Fenster verschieben
     Fensterrand ziehen          Größe ändern
     Doppelklick Titelleiste     maximieren / wiederherstellen
     Knöpfe in der Titelleiste   ✕ schließen   □ maximieren   – minimieren
     Taskleiste (oben)           Klick: anzeigen/wiederherstellen,
                                 Mittelklick: schließen, Rechtsklick: minimieren
     SUPER + linke Maustaste     Fenster überall greifen und verschieben
     SUPER + rechte Maustaste    Größe ändern

   PROGRAMME
     SUPER + Leertaste / R       Programme starten
     SUPER + Eingabe / T         Terminal
     SUPER + E                   Dateien
     SUPER + B                   Browser
     SUPER + I                   Einstellungen (Theme, Hintergrund, Tastatur …)
     SUPER + SHIFT + T           nächstes Theme
     SUPER + F1                  diese Übersicht

   FENSTER
     ALT + F4  ·  SUPER + Q      schließen
     SUPER + H                   minimieren
     SUPER + SHIFT + H           zuletzt minimiertes Fenster zurückholen
     SUPER + ↑                   maximieren / wiederherstellen
     SUPER + F                   Vollbild
     SUPER + V                   frei schwebend ↔ gekachelt
     SUPER + C                   zentrieren
     SUPER + P                   auf allen Arbeitsflächen anheften
     SUPER + ← / → / ↓           Fokus wechseln (SUPER + ALT + ↑: nach oben)
     SUPER + SHIFT + Pfeile      Fenster verschieben
     SUPER + CTRL + Pfeile       Größe ändern
     SUPER + J                   Teilung umschalten
     SUPER + G  /  SUPER + Tab   Fenster als Tabs gruppieren / nächster Tab
     ALT + Tab                   nächstes Fenster

   ARBEITSFLÄCHEN
     SUPER + 1 … 0               Arbeitsfläche 1–10
     SUPER + SHIFT + 1 … 0       Fenster dorthin verschieben
     SUPER + Bild↑ / Bild↓       vorige / nächste Arbeitsfläche
     SUPER + Mausrad             blättern
     3 Finger wischen            Arbeitsfläche wechseln (Touchpad)
     SUPER + S                   Notizzettel-Bereich ein/aus (Scratchpad)
     SUPER + ALT + S             Fenster in den Notizzettel-Bereich

   SYSTEM
     SUPER + L                   Bildschirm sperren
     SUPER + Escape              Abmelden / Neustart / Ausschalten
     Druck  ·  SUPER + SHIFT + S Bildschirmfoto (Bereich) → ~/Bilder/Screenshots
     SUPER + Druck               Bildschirmfoto aktives Fenster
     SUPER + SHIFT + C           Farbwähler
     SUPER + N                   Benachrichtigungen schließen
     ALT + SHIFT                 Tastaturlayout wechseln (bei mehreren)
     Medientasten                Lautstärke, Helligkeit, Wiedergabe
